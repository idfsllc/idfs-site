CAD File Preparation Guide

Best practices for preparing CAD files for fabrication, CNC machining, and 3D printing.

Preparing Your CAD Files

Proper CAD file preparation ensures accurate quotes and faster turnaround times. Follow these guidelines when preparing files for fabrication.

Preferred file formats:

  • STEP (.step, .stp)
  • IGES (.iges, .igs)
  • SolidWorks (.sldprt, .sldasm)
  • Fusion 360 (.f3d)
  • DXF (for 2D profiles)

File requirements:

  • Include all necessary dimensions and tolerances
  • Specify material requirements
  • Note any special requirements or finishes
  • Include assembly drawings if applicable

Tips for Better Results

Design for manufacturability:
Consider how your part will be made. Avoid features that are difficult or expensive to produce.

Include tolerances:
Specify critical dimensions and tolerances clearly in your drawings.

Material specifications:
Clearly indicate material type, grade, and any special requirements.

Quantity and timeline:
Include quantity requirements and any timeline constraints.
