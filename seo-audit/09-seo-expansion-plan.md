## SEO Best Practices for New Pages

### URL Structure
- Use lowercase
- Use hyphens for word separation
- Keep URLs descriptive but concise
- Match URL to page title when possible

### Title Tags
- 50-60 characters
- Include primary keyword
- Include location (Fayetteville GA or Atlanta GA)
- Include brand name (IDFS) at end

### Meta Descriptions
- 150-160 characters
- Include primary keyword naturally
- Include location
- Include call-to-action
- Unique for each page

### H1 Tags
- One H1 per page
- Include primary keyword
- Include location when relevant
- Match user intent

### Internal Linking
- Link from home page to new service pages
- Link from service overview to specific services
- Link from industry pages to relevant services
- Link from all pages to contact
- Use descriptive anchor text

### Schema Markup
- Service pages: Service schema
- Industry pages: Service schema with industry-specific types
- Location pages: LocalBusiness schema
- Resource pages: Article or HowTo schema
- All pages: BreadcrumbList schema (when breadcrumbs added)
